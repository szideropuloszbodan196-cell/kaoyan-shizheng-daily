# 考研政治·时政热点日报

面向 2027 考研备考者的时政热点学习网页，极简白底风格，覆盖考前一年（2025.12 — 2026.10）官方时政。

## 功能

- **关键词检索**：本地检索全部热点 + 一键网络搜索
- **热点云图**：高频主题词云，点击词即检索
- **全年时政刻度线**：关键节点可点击展开详解
- **热点详情视图**：左侧直接呈现原文 + 完整详细总结，右侧书本考点定位、批注讲解、关键金句、多方归纳
- **本月焦点**：5 张焦点卡片可点击，联系书本指出考点
- **领域统计 / 热度榜 / 模拟自测 / 考前备忘 / 历史归档**
- **整理下载**：Markdown / CSV / 复制文本

## 文件结构

| 文件 | 说明 |
|---|---|
| index.html | 页面入口 |
| styles.css | 极简视觉样式 |
| app.js | 渲染 / 详情 / 检索 / 云图 / 自测 / 下载逻辑 |
| data.js | 热点数据（年度总览 + 最新速览 + 详情） |
| data-extra.js | 扩展数据（完整总结 / 词云 / 时间线映射） |
| assets/ | 页面配图 |

## 更新方式

每日由豆包定时任务检索官方信息源（新华社、人民日报、中国政府网、求是网等），生成新数据后自动推送本仓库，GitHub Pages 自动发布。
